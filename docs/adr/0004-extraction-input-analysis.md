# ADR-0004: W3 추출 입력 데이터 실측 분석

- 상태: 채택
- 날짜: 2026-09-13

## 배경

2026-09-13 첫 실제 수집 성공 (공고 18건, Position 239건, 첨부 31건).
DB에 쌓인 screening_procedure_text를 직접 읽어 W3 추출 로직의 전제를 검증했다.

---

## 발견 1 — 키워드 매칭으로 필기 유무를 판정할 수 없다

같은 기관이 같은 시험을 공고마다 다르게 표기한다.

**한국전력공사 — 연구직 (｢필기｣ 단어 없음)**
```
1. 1차전형(서류전형) : 연구 및 업무실적(95점), 외국어성적(5점) / 5배수
2. 2차전형(직무능력검사, 인성·인재상·조직적합도 검사, 연구직 직무역량검사, 연구역량면접)
: 직무능력검사(100점), 인성·인재상·조직적합도 검사(적·부), 연구역량면접(100점, PT발표 포함) / 2배수
3. 3차전형(종합면접)
```

**한국전력공사 — 대졸수준 (같은 시험인데 ｢필기전형｣으로 표기)**
```
1. [1차] 서류전형
○ 외국어성적(100점), 자격증가점(사무20점, 기술40점) / 사무 : 50배수, 전기(배전, 송변전) : 10배수, 기술(전기 외) : 15배수
2. [2차] 필기전형
○ 직무능력검사(100점), 인성·인재상·조직적합도 검사 결과(적·부) / 2~3배수(공고문 참조)
3. [3차] 면접전형
○ 직무면접(50점), 경험면접(50점) / 1배수
```

→ `LIKE '%필기%'` 같은 룰 기반 사전 필터링을 넣으면 연구직 공고를
   "필기 없음"으로 잘못 분류한다. has_written_exam 판정도 LLM에 맡겨야 한다.

**진짜 필기가 없는 케이스 (대조군)**
```
[2026년도 제4차 전문직원 채용공고]
○ 1차전형(5배수) : 서류심사(자기소개서, 경력 등 종합평가) 100점, 인성·인재상·조직적합도 검사 : 적/부 판정
○ 2차전형(1배수) : 종합면접(전문성, 조직적합도, 업무계획 등 종합평가) 100점

[2026년 하반기 경력직원 채용]
1. 전형절차 및 방법
 가. 1차 서류전형 : 6배수 선발
 나. 2차 인성검사(온라인) : 면접전형 참고자료로 활용
  1) 인성검사 구성 : 공사 인재상, 조직부적응성, 성인지 항목 등
  2) 인성검사 응시완료자에 한하여 면접
```
→ 인성검사는 필기시험이 아니다. 이것도 구분해야 한다.

## 발견 2 — 전공시험 명칭이 기관마다 다르다

**한국남부발전 — "전공기초"**
```
□ 신입사원-대졸수준
 ○ 1단계(서류전형) : 외국어성적(50점), 자격증 가점(최대 50점)을 합산하여 고득점순 선발/ 30배수 선발
 ○ 2단계(필기전형) : NCS기반 선발평가 시행(직무적합평가, 직무능력평가, 전공기초) / 3배수 선발
 ○ 3단계(면접전형) : PT, GD, 실무역량, 인성 및 조직적합성 평가 / 2배수 선발
```

**한국도로공사 — "직무수행능력평가" (배점 30:70)**
```
○ 5급 공개채용
o 서류전형 : 적/부
o 필기전형 : 직업기초능력평가(30), 직무수행능력평가(70), 부가가점(해당 시)
- 합격배수 : 최종선발예정인원 10명이상(1.5배수), 4명이상~9명이하(2.5배수), 2~3명(3배수), 1명(4배수)
o 면접전형(PT 및 역량 면접) : 필기(50), 면접(50), 법정가점(해당 시)
```

**인천국제공항공사 — "직무수행능력평가(전공시험)" ← 동의 관계 확인 사례**
```
[일반직(사무,기술,전문,사회형평)]
ㅇ서류전형 : 20~50배수
- 공인어학성적 및 우대사항(100), 응시자격 충족여부(적/부)
ㅇ필기전형 : 3~4배수
- 직업기초능력평가(NCS)(50), 직무수행능력평가(전공시험)(50)
* 전문분야(관제)는 전공시험 미시행(NCS 100%)
```

**한국가스공사 — "직무수행능력"**
```
<일반직 신입, 사회형평(장애, 보훈)>
□ 서류전형 : 사무 50배수, 기술 30배수 선발
□ 필기전형 : 2~3배수 선발 / 인성검사 적합자 중 NCS직업기초능력(50%), 직무수행능력(50%) 및 가점합산
□ 면접전형 : 1배수 선발 / 직무면접(50%), 직업기초면접(50%) 및 가점합산
```

정리하면 동의어가 이만큼 된다.

| 개념 | 등장 표현 |
|---|---|
| 전공 | 전공기초 / 직무수행능력평가 / 직무수행능력 / 전공시험 / 직무능력검사 |
| NCS | 직업기초능력평가 / NCS직업기초능력 / 직무적합평가 / 직업기초능력 |

→ 프롬프트에 동의어 매핑 목록을 넣어야 한다. 룰 기반으로는 기관 수만큼 예외가 생긴다.

## 발견 3 — 한 공고 안에서 전형별로 시험 구성이 다르다

**한국가스공사 — 신입은 NCS+전공, 경력은 NCS만**
```
<일반직 신입, 사회형평(장애, 보훈)>
□ 필기전형 : 2~3배수 선발 / 인성검사 적합자 중 NCS직업기초능력(50%), 직무수행능력(50%) 및 가점합산

<일반직 경력>
□ 서류전형 : 적격자 전원 선발
□ 필기전형 : 5배수 선발 / 인성검사 적합자 중 NCS직업기초능력 및 가점합산
```

**인천국제공항공사 — 특정 분야만 전공 미시행**
```
ㅇ필기전형 : 3~4배수
- 직업기초능력평가(NCS)(50), 직무수행능력평가(전공시험)(50)
* 전문분야(관제)는 전공시험 미시행(NCS 100%)
```

→ 직렬 단위 저장 원칙이 실측으로 정당화됐다. **이 발견은 ADR-0003(시험 정보를
   직렬 단위로 저장)의 설계 원칙을 실측으로 뒷받침한다** — ADR-0003 작성 시 이
   섹션을 근거로 역참조할 것.
→ 추출 시 LLM에 screening_procedure_text 전체 + steps[]의 모집단위명 목록을
   함께 주고 모집단위별 ExamPlan 배열을 받아야 한다. 직렬을 하나씩 나눠
   질의하면 텍스트 안의 전형 구분(`<일반직 경력>`, `전문분야(관제)`)과
   매칭할 근거가 없다.

## 발견 4 — NCS 세부 영역이 면접 평가기준과 혼동된다 (가장 중요)

"의사소통"이 등장한 3건을 하나씩 확인한 결과 필기 출제 영역은 1건뿐이었다.

**✅ 신용보증기금 — 진짜 필기 출제 영역**
```
ㅁ 1차 객관식 필기 평가
ㅇ 평가대상 : 서류전형 합격자 중 응시정보 등록자
ㅇ 평가내용
- 직업기초능력 : 의사소통능력, 문제해결능력, 수리능력, 자원관리능력
- 직무전공 등 : 직무수행능력을 평가하기 위한 전공시험 등

□ 2차 논술 필기 평가
ㅇ 평가내용 : 직무분야 전공 및 직무수행과 연관된 주제
```

**❌ 인천국제공항공사 — 면접 평가기준**
```
ㅇ1차면접 : 1.5~2배수
- 직무면접(직무PT, 직무상황대처, 영어)(100)
- 평가기준 : 문제해결능력, 직무지식, 의사소통능력 등
ㅇ2차면접 : 1배수
- 종합면접(입사지원서 및 인재상 기반 종합 질의응답)(100)
- 평가기준 : 의사소통능력, 대인관계능력, 열정, 인성 등
```

**❌ 한국장학재단 — 면접 평가기준**
```
2. 직무역량면접(50점): 입사지원서 기반 직무역량 검증을 위한 질의응답

ㅇ 심층면접전형(채용예정인원의 1배수 선발)
- 입사지원서를 기반으로 응시자의 인성·가치관, 의사소통, 직무적합성을 종합적으로 평가
- 실무면접 30%와 심층면접 70%를 합산하여 고득점 순으로 최종합격자 선발
```

면접 평가기준과 필기 출제 영역이 동일한 NCS 용어를 쓴다. LLM이 이를 오인하면
사용자가 존재하지 않는 출제 영역을 준비하게 되므로 이 서비스에서 가장 치명적인
오류 유형이다. 게다가 표현이 명확해 confidence가 높게 나와 자동 승인으로 빠질
위험이 있다.

→ 프롬프트에 명시할 것:
```
NCS 영역은 필기전형 섹션 아래에 있을 때만 추출한다.
면접전형의 "평가기준", "평가항목"에 등장하는 능력 명칭은
필기 출제 영역이 아니므로 무시한다.
```
→ 검수 화면에서 이 케이스를 우선 확인 대상으로 표시하는 것도 검토.

## 실측 확보율

| 항목 | 18건 중 |
|---|---|
| NCS 세부 영역 (필기 출제) | 1건 (약 6%) |
| "의사소통" 단순 등장 | 3건 (17%) — 2건은 면접 평가기준 오탐 |
| 필기 시행 | LLM 판정 후 재측정 필요 (키워드로는 집계 불가) |

docs/01-requirements.md의 핵심 가치 우선순위(필기 유무 > 시험 유형 > 시험일 >
NCS 세부 영역)가 실측으로 검증됐다.

다만 NCS 영역 확보율이 예상보다 낮아 첨부파일 파싱(현재 세션 차단으로 미해결)의
중요도가 올라갔다. W3에서 첨부 다운로드를 해결하지 못하면 NCS 영역 필터는 사실상
빈 기능이 되므로, v1.0 필수 여부를 W3 결과 보고 재검토한다.
